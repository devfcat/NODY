# NODY

노드로 분기를 확인할 수 있는 스크립트 에디터 (WPF / .NET 8)

## 실행
Windows + .NET 8 SDK 필요.

    dotnet run          # 또는 Visual Studio 2022 에서 NODY.csproj 열기 → F5

첫 실행 시 프로젝트 폴더를 고르면, 그 폴더 안에 노드별 `.xlsx` 와 플로우 데이터 `nody_flow.json` 이 만들어진다.

## 조작
| 동작 | 방법 |
|---|---|
| 노드 생성 | 상단 '노드 생성' (생성 직후 이름 입력 상태) |
| 파일 열기 | 노드 더블 좌클릭 |
| 이름 수정 | 노드 우클릭 → Enter 확정 / Esc 취소 |
| 타입 변경 | 노드 이름 아래 드롭다운 (대사 파일 / 선택지 파일) |
| 이동 | 노드 드래그 |
| 삭제 | 노드 클릭 → 'Delete' 키 또는 '삭제하기' → 팝업 |
| 선 긋기 | '플로우 긋기' → 시작 노드 클릭 → 도착 노드 클릭 |
| 선 지우기 | '플로우 삭제' → 선 클릭 |
| 캔버스 이동 / 확대 | 빈 곳 드래그 또는 휠 버튼 드래그 / 마우스 휠 |
| 모드 종료 · 선택 해제 | Esc |

## 파일 구성
- `nody_flow.json` : 노드 위치·타입·연결(플로우). 에디터 전용, 클라이언트에서는 사용하지 않음
- `_trash/` : 노드 삭제 시 '파일도 삭제'를 고른 엑셀 파일이 이동되는 곳 (zip 내보내기에서 제외)
- 엑셀 템플릿 컬럼은 `Services/ExcelService.cs` 의 `HeaderFor()` 에서 수정
